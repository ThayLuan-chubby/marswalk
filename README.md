Welcome! This repository contains a web project designed to be run locally using Visual Studio Code and the Live Server extension.

**Prerequisites**

Before getting started, make sure you have the following installed:

1. Visual Studio Code (VS Code)

2. Live Server Extension by Ritwick Dey (Search for "Live Server" in the Extensions view Ctrl+Shift+X / Cmd+Shift+X inside VS Code and click Install).

**How to Run (Go Live)**

Follow these steps to run the project locally with live-reloading:

_1. Open the Project in VS Code:_

Open VS Code.

Go to File > Open Folder... and select the folder containing this project.

_2. Launch Live Server:_

In the VS Code file explorer sidebar, open your main HTML file (e.g., index.html).

Look at the bottom-right corner of the VS Code window and click the "Go Live" button.

Alternatively, right-click anywhere inside the index.html editor and select "Open with Live Server".

_3. View the App:_

Your default web browser will automatically open to http://localhost:5500 (or your configured port).

Any changes you save in your code will instantly refresh in the browser!
